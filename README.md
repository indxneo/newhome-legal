# A New Home: website

Public pages for the iPhone game **A New Home**, served with GitHub Pages:

| Page | Link | Use in App Store Connect |
|---|---|---|
| Home | https://indxneo.github.io/newhome-legal/ | Marketing URL (optional) |

Each page has an English and a Russian part. Support email: alishersv.dev@outlook.com.

The privacy policy says the game collects no data. That is true for the current build (no accounts, ads, analytics,
purchases or network use; Unity's analytics and crash reporting are off). Update the policy before adding anything
that sends data off the phone.
